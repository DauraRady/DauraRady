## 💡 My Testing Philosophy

### Test What Matters
- ✅ Focus on critical user journeys
- ✅ Test business logic, not UI pixels
- ✅ API-first when possible (faster, more reliable)
- ✅ Use E2E only for critical paths

### Quality as Business Risk
- ✅ Frame bugs in terms of business impact
- ✅ Prioritize by cost of failure, not just frequency
- ✅ Measure ROI of test automation
- ✅ Know when manual testing wins

### Production-Ready Code
- ✅ Error handling that makes sense
- ✅ Logging for observability
- ✅ Retry strategies for resilience
- ✅ Clear, actionable error messages

### AI/LLM Testing is Different
- ✅ Can't just assert on exact output
- ✅ Need semantic evaluation (not string matching)
- ✅ Test for hallucinations, off-topic responses
- ✅ Validate against prompt constraints
