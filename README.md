## 💡 My Testing Philosophy

### Test What Actually Matters
- ✅ Focus on critical user journeys (80/20 rule)
- ✅ Test business logic, not UI pixels
- ✅ Use API-first when possible (faster, more reliable)
- ✅ E2E only for the most critical paths
- ✅ Know when manual testing outweighs automation

### Quality is a Business Problem
- ✅ Frame bugs in business impact (revenue, compliance, customer churn)
- ✅ Measure ROI of test automation
- ✅ Prioritize by cost of failure, not just frequency
- ✅ Communicate with stakeholders in their language

### Production-Ready Code
- ✅ Error handling that makes sense (retry, backoff, logging)
- ✅ Structured logging for observability (trace, debug, error levels)
- ✅ Resilience patterns (timeouts, circuit breakers, fallbacks)
- ✅ Clear, actionable error messages
- ✅ Configuration over hardcoding

### AI/LLM Testing is Different
- ✅ Can't assert on exact output — use semantic evaluation
- ✅ Test for hallucinations, off-topic, refusal
- ✅ Validate against prompt constraints
- ✅ Measure consistency across multiple runs
- ✅ Combine multiple evaluation methods (not just one)
