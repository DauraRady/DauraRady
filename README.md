## 🧭 My Testing Philosophy

### Test What Actually Matters
- Focus on critical business journeys, not code coverage
- Test business logic with API-first approach when possible
- Use E2E selectively for the highest-risk paths
- Know when manual testing outweighs automation

### Quality is Risk Management
- Frame bugs in business impact: revenue, compliance, customer trust
- Prioritize by cost of failure, not just frequency
- Measure ROI of test automation investments
- Communicate test results in business language

### Production-Ready Code (Even in Prototypes)
- Proper error handling and retry strategies
- Structured logging for observability
- Configuration over hardcoding
- Clear, actionable error messages

### AI System Testing is Different
- Semantic evaluation, not string matching
- Measure for hallucinations, off-topic responses, refusals
- Validate against prompt constraints
- Test consistency across multiple runs
